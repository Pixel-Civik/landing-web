# Landing Web

Marketing site de CrashGuard construido con React 19, Vite y Tailwind CSS.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run preview
npm run lint
```

## Deploy

- Dockerfile: [Dockerfile](./Dockerfile)
- Produccion: [cloudbuild.yaml](./cloudbuild.yaml)

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React
